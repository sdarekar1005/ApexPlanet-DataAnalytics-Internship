# Task 2 - Exploratory Data Analysis (EDA)

## Objective
To analyze the Superstore dataset and identify meaningful business insights using data visualization techniques.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code
- GitHub

## Dataset Overview
- Records: 9,994
- Columns: 21
- Missing Values: 0

## Analysis Performed
- Sales by Region
- Sales by Category
- Profit by Category
- Top 10 Products by Sales
- Monthly Sales Trend

## Key Insights
- West region generated the highest sales.
- Technology category contributed the highest revenue.
- Profit distribution varied across categories.
- Top-selling products contributed significantly to overall sales.
- Monthly sales trends showed fluctuations over time.

## Output
Generated multiple charts and extracted business insights from the dataset.
