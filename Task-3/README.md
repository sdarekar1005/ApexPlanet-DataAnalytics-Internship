# Task 3 - Superstore Sales Dashboard

## Project Overview
This project is developed as part of the ApexPlanet Software Pvt. Ltd. Data Analytics Internship (Task 3). The objective is to create an interactive Power BI dashboard using the Sample Superstore dataset.

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Total Orders KPI
- Sales by Region
- Profit by Category
- Sales by Category
- Monthly Sales Trend
- Interactive Slicers:
  - Region
  - Category
  - Segment

## Tools Used

- Microsoft Power BI Desktop
