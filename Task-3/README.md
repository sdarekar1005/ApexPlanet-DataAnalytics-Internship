## 📌 Project Overview
This project is developed as part of the ApexPlanet Software Pvt. Ltd. Data Analytics Internship (Task 3). The objective is to create an interactive Power BI dashboard using the Sample Superstore dataset to analyze sales performance, profit, quantity, orders, and regional trends.

## 📊 Dashboard Features

- Total Sales KPI Card
- Total Profit KPI Card
- Total Quantity KPI Card
- Total Orders KPI Card
- Sales by Region (Column Chart)
- Profit by Category (Bar Chart)
- Sales by Category (Bar Chart)
- Monthly Sales Trend (Line Chart)
